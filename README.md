# Citizen Registry System

A Django-based citizen registry system with authentication, citizen search, daily/monthly usage limits, custom admin dashboard, and PostgreSQL backend.

## Features

- User registration and login
- Citizen search system
- Daily and monthly usage limits
- Token-based search usage
- Custom admin dashboard
- PostgreSQL database
- Search result count
- Search execution time
- 100K+ sample data generator

## Tech Stack

- Python
- Django
- PostgreSQL
- Django ORM
- HTML/CSS
